# BoxFab desktop template

The sandbox template behind `boxfab-desktop` / `@boxfab/desktop`: Ubuntu 22.04 with Xfce, Chrome,
Firefox ESR, VS Code, LibreOffice, x11vnc and noVNC. It is the upstream
[e2b-dev/desktop template](https://github.com/e2b-dev/desktop/tree/main/template), built with the
BoxFab SDK instead of the E2B one.

`template.py`, `build_*.py` and `files/` are generated by `scripts/sync_upstream.py` (Apache-2.0,
see `LICENSE-E2B-DESKTOP`). They differ from upstream in the SDK import and the BoxFab branding:
the wallpaper, the noVNC page title and icons, and the hostname `boxfab.local` (see UPSTREAM.md). `pyproject.toml` and this
README are this repository's own.

## Build

```bash
cd template
uv sync
BOXFAB_API_KEY=e2b_*** uv run python build_dev.py    # alias desktop-dev, for testing
BOXFAB_API_KEY=e2b_*** uv run python build_prod.py   # alias desktop, the SDK's default template
```

Both build with 8 vCPU and 8 GiB of memory, as upstream.

The SDKs create sandboxes from the template named `desktop`, which BoxFab provides to every team. To
use your own build instead, pass its name: `Sandbox.create(template="desktop-dev")` in Python,
`Sandbox.create('desktop-dev')` in JS.

`build_docker.py` prints the template as a Dockerfile (upstream's CI uses it to push an image to
Docker Hub; BoxFab does not).

## Build-time sources

The build clones noVNC from `https://github.com/e2b-dev/noVNC` (branch `e2b-desktop`) and
websockify from `https://github.com/novnc/websockify` (tag `v0.12.0`), and installs Chrome, VS Code
and Firefox ESR from the Google, Microsoft and Mozilla Team repositories. These are upstream's
choices and are unchanged in the first release.
