# BoxFab desktop template

The sandbox template behind `boxfab-desktop` / `@boxfab/desktop`: Ubuntu 22.04 with Xfce, Chrome,
Firefox ESR, VS Code, LibreOffice, x11vnc and noVNC, with the BoxFab wallpaper, the noVNC page
title and icons, and the hostname `boxfab.local`.

`template.py`, `build_*.py` and `files/` are generated by `scripts/sync_upstream.py` (Apache-2.0,
see `LICENSE`); see [UPSTREAM.md](../UPSTREAM.md) for what they are generated from and what
changes. `pyproject.toml` and this README are this repository's own.

## Build

```bash
cd template
uv sync
BOXFAB_API_KEY=e2b_*** uv run python build_dev.py    # alias desktop-dev, for testing
BOXFAB_API_KEY=e2b_*** uv run python build_prod.py   # alias desktop, the SDK's default template
```

Both build with 8 vCPU and 8 GiB of memory.

The SDKs create sandboxes from the template named `desktop`, which BoxFab provides to every team. To
use your own build instead, pass its name: `Sandbox.create(template="desktop-dev")` in Python,
`Sandbox.create('desktop-dev')` in JS.

`build_docker.py` prints the template as a Dockerfile.

## Build-time sources

The build clones noVNC from `https://github.com/e2b-dev/noVNC` (branch `e2b-desktop`, pinned to a
commit) and websockify from `https://github.com/novnc/websockify` (tag `v0.12.0`), and installs
Chrome, VS Code and Firefox ESR from the Google, Microsoft and Mozilla Team repositories.
