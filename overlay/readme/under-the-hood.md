BoxFab sandboxes are [Firecracker](https://firecracker-microvm.github.io/) microVMs, run on the
open-source [E2B](https://github.com/e2b-dev/infra) sandbox infrastructure. The template and the
examples in this repository are derived from the open-source
[E2B Desktop](https://github.com/e2b-dev/desktop) project, and the SDKs from the E2B Desktop SDKs;
[UPSTREAM.md](UPSTREAM.md) lists every change.
